# Mini Voice для Windows

1. Розпакуй усю папку та відкрий mini-client.exe.
2. Введи адресу свого сервера: wss://твій-домен:4433.
3. Введи username і пароль → Register.
4. Додай друга: Add friend → інший користувач натискає Accept friend.
5. Вибери друга → New chat; для дзвінка Call → Accept call.

Друзям не потрібні Oracle-акаунти чи власні сервери. Сервер має бути налаштований
один раз оператором: https://github.com/zettazet/willownutstea/blob/main/mini-voice/docs/HOSTING.md
Для Oracle Ubuntu потрібен Linux-сервер, а не Windows mini-server.exe.

mini-server.exe у цій папці — альтернативний ручний Windows-сервер. Потрібні
server.json (копія server.example.json) та власна коректна TLS-пара; запуск
із PowerShell у папці: .\mini-server.exe .\server.json.

Використовуй навушники. Echo cancellation не реалізовано. Збірки unsigned;
Windows GUI, фізичне аудіо та RAM/CPU тут не перевірялися. Дивись docs/VALIDATION.md.
Під час поширення зберігай LICENSE, THIRD-PARTY-NOTICES.txt і compiler-notices.

## Робота у фоні та діагностика

Хрестик, Alt+F4 або згортання ховають клієнт у системний трей біля годинника.
Повідомлення, підключення та поточний дзвінок продовжують працювати; мікрофон
залишається у попередньому стані. Наведи курсор на іконку: підказка показує
Background/Open, стан підключення та активний дзвінок/вимкнений мікрофон.
Іконка може бути у прихованих значках під стрілкою біля годинника.

Клік на іконку відкриває вікно. Права кнопка → Open Mini Voice або
Exit (end calls). Кнопка Exit app у вікні також повністю завершує клієнт.
Якщо трей недоступний, вікно залишається доступним через панель завдань.
Режим у фоні не означає автозапуск після перезавантаження Windows і не працює,
коли ПК вимкнений або спить.

Якщо клієнт завершується з помилкою, перевір журнал:
%LOCALAPPDATA%\MiniVoice\client.log (можна вставити у Win+R).
Журнал містить етапи запуску та місце panic без тексту повідомлень, паролів
і токенів; попередній журнал — client.previous.log. При внутрішній помилці
показується діалог із розташуванням журналу. Збої Windows до запуску програми
можуть не потрапити в журнал.

Оновлення: **Audio / Profile** — гучність, пристрої, аватар і Show Avatars.
Enter надсилає, Shift+Enter додає новий рядок. Для аватарів онови також сервер.
Деталі: [Audio / Profile та оновлення сервера](https://github.com/zettazet/willownutstea/blob/main/mini-voice/docs/CLIENT-UPDATE.md).

Audio / Profile → **Voice cleanup** зменшує гул, високочастотне шипіння та тихий
фоновий шум мікрофона. Увімкнено за замовчуванням; можна вимкнути під час дзвінка.
Аватари дзвінка — квадратні, 40×40. Для цього оновлення сервер змінювати не потрібно.

Новий теплий інтерфейс: **Insert** вимикає/вмикає мікрофон у дзвінку навіть у треї.
**Audio / Profile → RNNoise cleaner** прибирає фоновий шум; **Threshold**
за замовчуванням −50 dBFS (до −30 — сильніше приглушення, до −60 — для тихого голосу).
RNNoise можна вимкнути для меншого навантаження CPU, зберігши базові фільтри.
**Soft sounds** — тихі звуки входу/виходу, учасників та мікрофона; можна вимкнути.
Для цього оновлення потрібен лише новий клієнт.
